# Contribuer

Merci de votre intérêt !

## Workflow

1. Créez une branche depuis `main` (ou forkez le dépôt)
2. Commits au format `type(scope): message`
   (ex: `fix(auth): corrige le refresh du token`)
3. Ouvrez une Pull Request en remplissant le template
4. La CI (tests, CodeQL, dependency review) doit passer au vert

## Règles

- Un commit = une chose, une PR = un sujet
- Aucun secret dans le dépôt — la push protection bloquera le push
- Documentez les changements de comportement dans le README ou `docs/`
