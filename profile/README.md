# art-qalam-fr

Organisation regroupant nos serveurs MCP, outils d'automatisation et projets internes.

## Sécurité & qualité

Tous nos dépôts publics bénéficient de :

- Secret scanning + push protection
- Dependabot (alertes + mises à jour automatiques)
- CodeQL (analyse statique du code)
- Dependency review sur chaque PR
- CI automatisée (GitHub Actions)

Une vulnérabilité ? Utilisez l'onglet **Security** du dépôt concerné —
voir notre [politique de sécurité](https://github.com/art-qalam-fr/.github/blob/main/SECURITY.md).
